## ALE H-to-T Geometry Contract

The production `H -> T -> E` orchestrator now carries a structured geometry
epoch contract:

- If `H` reports `ale_geometry_committed=true`, it must provide a non-empty
  `geometry_epoch`.
- `T` must report the same `geometry_epoch`.
- A stale `T` geometry epoch fails before `E` is executed.
- Successful ALE geometry handoff reports:
  `ale_geometry_committed=true` and
  `thermal_geometry_epoch=<committed_epoch>`.

This guards the required production semantics: with ALE enabled, thermal
diffusion operates on the committed post-hydro mesh, not the old mesh.
