下面就是我建议你在**进入 PPM 前必须先收掉的 3 个 blocker**。这不是锦上添花，而是避免你把高阶重构叠到一个还不够稳的球坐标核上。论文已经明确：DEC3D 的球坐标 3D hydro 需要三层 ghost，极点和原点不是普通边界，而是通过 `theta/phi` 的 3D 关系从内部单元映射 ghost；外边界则是零流入边界。fileciteturn29file1turn29file0 同时你自己的 `P1` 规范也已经写死：PPM 必须是**真 PPM**、要有三层 ghost、球坐标几何项和 macro-zoning/ALE 都是正式能力，不是临时壳。fileciteturn29file15turn29file5turn29file8

## 1. 失败路径必须返回**有信息的失败**，不能再 `return {}`
这是最先修的。

你前面已经把“事务性提交”修了，这很好。但 `HydroOperator::advance()` 只要 hydro 子步骤失败，仍然不该把 diagnostics/evidence 丢掉。现在正确的 contract 应该是：

- `success = false`
- `failure_reason` 非空
- `execution_evidence` 至少保留到失败点
- `diagnostics payload` 至少包含：
  - 哪个 directional path 失败了
  - 哪个 boundary/source step 失败了
  - 最近一次 write-set / invalidation / feasibility check 的结果
- `updated_fields = 0`

要加的红测很简单：构造一个故意失败的 hydro case，断言 `StageResult` 失败时**仍然语义完整**，而不是空对象。  
这条是工程 blocker，不是数值 blocker，但必须先过。你前面的项目级 gate 已经把“missing diagnostics / unproven runtime-path execution / stale-cache reads 都算失败”写死了，所以这里不能例外。fileciteturn16file0turn16file10

## 2. 把 radial boundary contract 明确化，不要再让它继续当 placeholder
这是你进入真正 shock-tube / P1 数值验收前必须补的。

论文在 spherical mesh DEC3D 里对外边界的文字很明确：**外径使用 zero inflow boundary condition**，至少对密度、总压强和径向速度给出一致边界语义；而极点/原点则不是普通边界。fileciteturn29file0turn29file1  
你现在最大的短板不是 `theta`/`phi` 了，而是 `r` 方向的两端还在用临时做法。下一步要把它升级成正式 contract：

### 建议的最小实现
在 `src/hydro/driver/radial_boundary_contract.*` 里集中做 3 件事：

1. **外边界 ghost state 生成**
   - `rho_g = rho_N`
   - `P_g = P_N`
   - `v_r,g = min(v_r,N, 0)` 或按你最终决定的 zero-inflow 语义固定
   - 切向速度先做零梯度拷贝
   - `chi_e` 先做零梯度拷贝  
   这一步的“`v_r` 到底 clamp 还是镜像”要写进 assumption ledger，因为论文片段当前没有把外边界所有变量的完整代数形式写成可直接抄代码的界面态公式。fileciteturn29file0turn16file7

2. **内边界 / 原点侧 contract**
   论文明确说 3D perturbing flows 在原点和极点**不施加普通边界条件**，而是靠 3D 映射得到 ghost 值。fileciteturn29file0turn29file1  
   所以在 3D spherical hydro 里，原点侧不要发明一条“普通物理边界”；你的实现应该和极点一样，统一归到 ghost substrate 里的映射规则，而不是独立的 fixed BC。

3. **radial sweep 不再直接用边界单元物理通量顶界面**
   现在这一条必须删掉。  
   改成：**边界界面 = ghost state + interior state -> HLLC**。  
   只有这样，后面的 shock tube、ALE、MPI seam 才不会被边界 placeholder 污染。

### 这条要加的测试

- `test_hydro_radial_boundary_ghost_state.cpp`
- `test_hydro_shock_tube_boundary_sanity.cpp`

目标不是一步到位追精确解，而是先证明：
- 边界 contract 已明确
- 不是 placeholder
- 不会在最小 shock case 上制造伪波/伪流入

## 3. 把 `theta/phi` 边界 helper 升级成**正式 hydro ghost substrate**，然后再上 PPM
这是数值 blocker。

你现在已经有：
- `PrepareThetaPoleBoundaryStates(...)`
- `PreparePhiPeriodicBoundaryStates(...)`

方向是对的，但它们还是**界面级 helper**，不够支撑真正的 PPM。你的 `P1` 文档已经明确要求：

- direction-local characteristic PPM
- three hydro ghost layers
- troubled-cell downgrade to first-order HLLC fileciteturn29file15

所以 PPM 前必须先补成统一的 ghost substrate：

### 目标接口
建议直接长成两层：

#### A. 当前态 ghost fill
- `FillHydroRadialGhosts(view, ng)`
- `FillHydroPhiPeriodicGhosts(view, ng)`
- `FillHydroThetaPoleGhosts(view, ng)`

#### B. 方向就绪接口
- `PrepareDirectionalGhosts(view, Direction dir, ng)`

这样 reconstruction 层只管：
- 进入 `r/theta/phi` 方向前
- 调 `PrepareDirectionalGhosts(...)`
- 然后在完整 ghost line 上做 PPM

### `theta` 极点 ghost 的正式规则
继续沿你已经实现的那套，但要推广到 `ng=3`：

对标量：
\[
Q(i,1-g,k)=Q(i,g,k+\Delta k_\pi),\quad
Q(i,N_\theta+g,k)=Q(i,N_\theta+1-g,k+\Delta k_\pi)
\]
其中 \(\Delta k_\pi = N_\phi/2\)（取模）。这正是论文 Eq. (5.18) 的核心映射。fileciteturn29file1

对球坐标动量分量，继续用你已经接入的最小规则：
- `mom_r` 保持
- `mom_theta` 反号
- `mom_phi` 反号

这一步仍然要继续记在 assumption ledger，因为论文片段给出了 ghost cell 的 3D 位置关系，但没有把球基底分量翻转规则逐行写成源码级算法。fileciteturn29file1turn16file7

2. **radial-only vs full-direction distinguishability**

   靠近极区的 case 上不出 NaN，不长出异常大的 `mom_theta/mom_phi`，并且不会出现明显伪波。
