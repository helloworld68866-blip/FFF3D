# 一、先把你要离散的方程写死

Woo 论文在球坐标下写的 hydro 主方程是：

\[
\frac{\partial \vec Q}{\partial t}
+\frac{1}{r^2}\frac{\partial (r^2 \vec F_r)}{\partial r}
+\frac{1}{r\sin\theta}\frac{\partial (\sin\theta \vec F_\theta)}{\partial \theta}
+\frac{1}{r\sin\theta}\frac{\partial \vec F_\phi}{\partial \phi}
=
\vec S ,
\]
其中状态向量和几何源项向量是：  
\[
\vec Q =
\begin{bmatrix}
\rho \\
\rho v_r \\
\rho v_\theta \\
\rho v_\phi \\
\varepsilon
\end{bmatrix},
\qquad
\vec S =
\begin{bmatrix}
0 \\
2P/r + \rho(v_\theta^2+v_\phi^2)/r \\
-\rho v_\theta v_r/r + (\cos\theta/\sin\theta)\,(\rho v_\phi^2+P)/r \\
-\rho v_r v_\phi/r - (\cos\theta/\sin\theta)\,\rho v_\theta v_\phi/r \\
0
\end{bmatrix}.
\]
这就是你必须加进去的**几何源项本体**。fileciteturn24file8

你现在项目里的 authoritative hydro 变量是：

\[
[\rho,\; mom_r,\; mom_\theta,\; mom_\phi,\; E_{fluid,total},\; \chi_e]
\]

所以把上面的源项改写成你代码里真正该用的形式，就是：

\[
S_\rho = 0
\]

\[
S_{mom_r}
=
\frac{2P}{r}
+
\frac{mom_\theta^2 + mom_\phi^2}{\rho\,r}
\]

\[
S_{mom_\theta}
=
-\frac{mom_\theta\,mom_r}{\rho\,r}
+
\frac{\cot\theta}{r}
\left(
\frac{mom_\phi^2}{\rho}+P
\right)
\]

\[
S_{mom_\phi}
=
-\frac{mom_r\,mom_\phi}{\rho\,r}
-
\frac{\cot\theta}{r}
\left(
\frac{mom_\theta\,mom_\phi}{\rho}
\right)
\]

\[
S_{E} = 0
\]

\[
S_{\chi_e}=0
\]

这里最后两条 `E` 和 `chi_e` 不更新，不是因为论文说它们永远没源项，而是因为你当前 phase-one hydro contract 已经明确把 source half-step 限定为：**只动真正需要几何源项的守恒量，不改 `rho`、`E`、`chi_e`**。这条约束来自你现在锁定的 hydro design，不是论文原文逐字规定。fileciteturn24file5

# 二、几何源项应该怎么加：最稳的做法是 source half-step

你当前这条线最稳的做法，不要把几何源项硬塞进 HLLC 里，而是按你已经锁定的 phase-one contract 走：

\[
U^n
\xrightarrow{S/2}
U^{(a)}
\xrightarrow{r\text{-sweep}}
U^{(b)}
\xrightarrow{\theta\text{-sweep}}
U^{(c)}
\xrightarrow{\phi\text{-sweep}}
U^{(d)}
\xrightarrow{S/2}
U^{n+1}.
\]

也就是：

1. **source half-step**
2. `r` sweep
3. `theta` sweep
4. `phi` sweep
5. **source half-step**

这和你前面已经定下来的 hydro contract 是一致的。fileciteturn24file5

## 具体单元级更新

对每个 owned cell `(i,j,k)`，在 source half-step 里只更新动量：

\[
mom_r^{n+1/2}
=
mom_r^n + \frac12 \Delta t \, S_{mom_r}(U^n)
\]

\[
mom_\theta^{n+1/2}
=
mom_\theta^n + \frac12 \Delta t \, S_{mom_\theta}(U^n)
\]

\[
mom_\phi^{n+1/2}
=
mom_\phi^n + \frac12 \Delta t \, S_{mom_\phi}(U^n)
\]

而：

\[
\rho,\ E_{fluid,total},\ \chi_e
\]
在这个 source half-step 里保持不变。

## 为什么先这么做
因为这一步的目标是先把**球坐标方程写完整**，而不是一上来追求最复杂的 unsplit source-coupled Godunov。  
你后面做 PPM、ALE、macro-zoning 时，先有一个**方程完整的一阶/低阶核**，远比继续在“少了几何源项”的核上叠复杂度要稳。

# 三、静态网格上三个方向的有限体积更新要怎么写

先不带 ALE，更新公式写成：

\[
(VU)^{n+1}_{ijk}
=
(VU)^n_{ijk}
-\Delta t\,
\Big[
A_r^{i+1/2}F_{r,i+1/2}
-
A_r^{i-1/2}F_{r,i-1/2}
\Big]
\]
\[
-\Delta t\,
\Big[
A_\theta^{j+1/2}F_{\theta,j+1/2}
-
A_\theta^{j-1/2}F_{\theta,j-1/2}
\Big]
-\Delta t\,
\Big[
A_\phi^{k+1/2}F_{\phi,k+1/2}
-
A_\phi^{k-1/2}F_{\phi,k-1/2}
\Big]
+\Delta t\,V_{ijk}\,S_{ijk}.
\]

而在你的 split code 里，不必一次全写成 unsplit，只要在每个方向用对应面面积和体积做 sweep 即可。

# 四、你现在真正要补的：`theta/phi` 边界处理

这是当前最关键的一步。

1. `exchange_radial_halo(...)`

这条顺序你自己以前也已经锁死了。fileciteturn24file5

# 五、`phi` 周期边界：直接周期映射

这一条最简单，论文 Eq. (5.18) 已经给出了：

\[
Q(ri,\theta_j,\phi_{1-g}) = Q(ri,\theta_j,\phi_{N_\phi+1-g})
\]
\[
Q(ri,\theta_j,\phi_{N_\phi+g}) = Q(ri,\theta_j,\phi_g),
\qquad g=1,2,3
\]

也就是对每层 ghost：

- 左侧 ghost 从右端 interior 抄
- 右侧 ghost 从左端 interior 抄

## 代码建议
对任意 field：

```cpp id="8jzftm"
for (int g = 1; g <= ng; ++g) {
    field(i, j, 1 - g)     = field(i, j, Nphi + 1 - g);
    field(i, j, Nphi + g)  = field(i, j, g);
}
```

对标量和动量都一样，因为这只是纯粹的 `phi` 周期，不涉及跨极点的基向量翻转。

# 六、`theta` 极点处理：不是边界外推，而是“跨极点映射 + phi 半圈平移”

这一条必须按论文思路来，不能再拿边界单元物理通量顶着用。

论文 Eq. (5.18) 给出的标量 ghost 映射关系本质是：

\[
Q(ri,\theta_{1-g},\phi_k)
=
Q(ri,\theta_g,\phi_{k+\Delta k_\pi})
\]
\[
Q(ri,\theta_{N_\theta+g},\phi_k)
=
Q(ri,\theta_{N_\theta+1-g},\phi_{k+\Delta k_\pi})
\]

其中  
\[
\Delta k_\pi = N_\phi/2
\]
也就是跨极点时，要在 `phi` 上平移半圈。论文片段里就是通过 `phi + Nphi/2` 的关系来表达这个 3D 映射。fileciteturn24file3

## 标量字段的实现
对：

- `rho`
- `E_fluid_total`
- `chi_e`
- 以及任何纯标量 cached field

做：

```cpp id="bm0up1"
int kp = k + Nphi/2;
if (kp > Nphi) kp -= Nphi;

for (int g = 1; g <= ng; ++g) {
    scalar(i, 1 - g,      k) = scalar(i, g,              kp);
    scalar(i, Ntheta + g, k) = scalar(i, Ntheta + 1 - g, kp);
}
```

这部分是**论文直接支持**的。

# 七、跨极点时动量/速度分量怎么变号

这一步论文没有把分量变号规则逐字写成现成实现，但如果你存的是**球坐标基底下的分量**，那么跨极点时必须做基向量变换。  
这是一个**必须记入 assumption ledger 的工程补全**。

如果采用“通过 `phi -> phi + π` 把 ghost 点映射到 interior 对应点”的实现，那么基向量关系会导致：

- \(e_r\) 映射后保持一致
- \(e_\theta\) 反号
- \(e_\phi\) 反号

因此，对球坐标分量，推荐的 ghost 变换是：

\[
mom_r^{ghost} = +\,mom_r^{mapped}
\]
\[
mom_\theta^{ghost} = -\,mom_\theta^{mapped}
\]
\[
mom_\phi^{ghost} = -\,mom_\phi^{mapped}
\]

如果你在 primitive 层处理，也是同样规则：

\[
v_r^{ghost} = +\,v_r^{mapped}
\]
\[
v_\theta^{ghost} = -\,v_\theta^{mapped}
\]
\[
v_\phi^{ghost} = -\,v_\phi^{mapped}
\]

## 代码建议
```cpp id="yqb6zc"
for (int g = 1; g <= ng; ++g) {
    mom_r(i, 1 - g,      k) = +mom_r(i, g,              kp);
    mom_t(i, 1 - g,      k) = -mom_t(i, g,              kp);
    mom_p(i, 1 - g,      k) = -mom_p(i, g,              kp);

    mom_r(i, Ntheta + g, k) = +mom_r(i, Ntheta + 1 - g, kp);
    mom_t(i, Ntheta + g, k) = -mom_t(i, Ntheta + 1 - g, kp);
    mom_p(i, Ntheta + g, k) = -mom_p(i, Ntheta + 1 - g, kp);
}
```

## 这一步为什么必须做
因为如果你只是简单复制数值，不做分量翻转，那么靠近极点时：

- `theta` sweep 会错
- `phi` sweep 会错
- 角向动量会出现伪波
- 你后面无论 PPM、ALE、macro-zoning 做得多漂亮，极区都不可信

所以这一步不能省。

# 八、把 `theta` 边界处理真接进当前 hydro 路径

你当前的问题，不是没有 ghost helper，而是 **hydro advance 还没有真正依赖这套 ghost contract**。

所以你应该这样改：

## 8.1 每个 sweep 前准备当前态的 ghost
在 static-grid full directional hydro 里，建议固定：

```cpp id="cj7l69"
exchange_radial_halo(work);
fill_phi_periodic_and_theta_pole(work);
```

然后再进入：

- radial sweep
- refresh if needed
- theta sweep
- refresh if needed
- phi sweep

尤其是以后上 PPM 时，**进入任一方向 reconstruction 前，该方向所需的 ghost 都必须是当前态**。这条也是你之前 hydro design 里已经定死的。fileciteturn24file5

## 8.2 不要再用“边界界面通量 = 边界单元物理通量”
这一条现在必须删掉。  
因为对 `theta` 方向来说，极点不是普通边界外推，而是 ghost remap 后的内部对应界面。  
所以 `theta` sweep 时的边界界面态必须来自：

- remapped ghost cell
- 相邻 interior cell
- 再送进 HLLC

而不是直接：

- `F_theta(left_boundary) = physical_flux(cell_0)`

这一步一改，你当前 static-grid 3D hydro 才开始真正站上球坐标 3D 的边界语义。

# 九、最小 source + 边界 的代码组织

我建议你在当前 `hydro_operator.advance()` 上，直接改成下面这种骨架：

```cpp id="6tu5g2"
StageResult HydroOperator::advance(...) {
    // 1) build hydro-local view from canonical truth
    auto view = BuildHydroStateView(state);

    // 2) source half-step on momentum only
    ApplySphericalGeometrySourceHalfStep(view, mesh, dt);

    // 3) current-state ghost preparation
    ExchangeRadialHalo(view);
    FillPhiPeriodicAndThetaPole(view);

    // 4) r sweep
    SweepDirection(view, mesh, Direction::R, dt);

    // 5) refresh current ghosts
    ExchangeRadialHalo(view);
    FillPhiPeriodicAndThetaPole(view);

    // 6) theta sweep
    SweepDirection(view, mesh, Direction::Theta, dt);

    // 7) refresh current ghosts
    ExchangeRadialHalo(view);
    FillPhiPeriodicAndThetaPole(view);

    // 8) phi sweep
    SweepDirection(view, mesh, Direction::Phi, dt);

    // 9) source half-step again
    ApplySphericalGeometrySourceHalfStep(view, mesh, dt);

    // 10) authorized writeback:
    // rho/mom/E_fluid_total + chi_e->Pe->E_electron
    CommitHydroWriteback(view, state);

    // 11) diagnostics / execution evidence
}
```

如果你现在还没接 MPI，`ExchangeRadialHalo` 可以先在单 rank 下是 no-op；  
但 `FillPhiPeriodicAndThetaPole` 不能再是 no-op。
